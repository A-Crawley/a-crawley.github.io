---
title: Oddly familiar
date: 2026-10-15
summary: If you have finished the game before, the next run remembers a little.
---

Once you have reached an ending, a new game carries a few quiet hints of it. The log opens with a line about the village feeling oddly familiar. The Sky gets three extra notes that depend on how it ended last time (something burnt once, or a border that was never drawn). And partway through the research, the rival says something that depends on the kind of run you had.

It is only words. There are no bonuses, nothing is cheaper or faster, and your first run is exactly as it was.

The game remembers the last finished run on this device only, next to your notation setting. Starting a new game keeps it, and so does importing a save. There is no button to forget it yet: clearing this site's data does it.

Saves from before this change load as first runs.

**Not tested:** on a real phone, or by playing a second run all the way through. All the wording is a first pass.
