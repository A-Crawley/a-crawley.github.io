---
title: Machines run on wood
date: 2026-10-15
summary: Machines now burn wood, so automation is no longer free.
---

Every machine (Automated forager, Sawmill bot, Builder drone) now burns a little wood each second it works. The wood counter shows what is left after the burn, and the Village panel has a new **Power** row that says whether the machines are fuelled or short, and how much they burn.

If the village cannot cover the burn, every machine slows in proportion. It never drops below half speed, so a fuel shortage will not starve you. The log says so when it happens.

The burn is light at the usual pace, so most players will see it as a smaller wood number rather than a crisis. It matters if you build lots of machines and no sawmills.

To keep the Automated forager worth buying, it now makes 7 food a second instead of 6.

Saves from earlier versions need nothing: this is worked out from what you own.

**Not tested:** on a real phone, or with a person playing stage 2 on purpose to run out of power. The size was set with the simulation only, and it may be too gentle. Tell me if you never notice it.
